## Context

What situation forces a decision? Include the constraints that are not
negotiable and the ones that merely look that way. State facts that were
verified, and mark the ones that were assumed.

## Decision

What we will do, in the active voice. One paragraph if possible.

## Consequences

What this costs us, not just what it buys. Include the things that become harder
and the doors this closes. If there is a point at which this decision should be
revisited, say what would trigger that.

## Alternatives considered

Each with the reason it was not chosen. "We did not think of it" is not a
reason; if an option was never seriously evaluated, leave it out.
